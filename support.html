サポート — ボイスカレンダー

最終更新: 2026年7月19日

ボイスカレンダーは、話すだけで端末のカレンダーに予定を追加できるアプリです。OS の既定に設定しているカレンダーに、声で予定を書き込めます。

使い方

  1. アプリを開きます（または Siri で「ボイカレ 開いて」）。
  2. 「明日10時30分 会議」のように話します。日時とタイトルがフォームに入ります。
  3. 「カレンダーに保存」を押すと、端末のカレンダーに追加されます。

メモとしても使えます。日時を言わなければ「今」として記録します。例:「現在 東京駅についた」→ 今の日時で「東京駅についた」がカレンダーに残ります。

よくある質問

予定はどのカレンダーに入りますか？

iOS で「既定（デフォルト）」に設定しているカレンダーに入ります。変えるには「設定 → カレンダー → デフォルトカレンダー」で選び直してください。

Google カレンダーに入れたい

iOS の「設定 → カレンダー → アカウント」で Google を追加し、そのカレンダーを既定に設定してください。アプリは Google と直接通信せず、OS が同期します。

Siri で開けない／別名で開きたい

「ヘイシリ、ボイカレ 開いて」または「ボイスカレンダー 開いて」で開きます。開いた直後は自動で録音が始まります（白紙のときだけ）。

声がうまく入らない

短く区切って話すと認識が安定します（1回の発話で1つの項目）。マイクと音声認識の許可が必要です（「設定 → ボイスカレンダー」で確認できます）。認識は可能な限り端末内で行います。

入った予定を消したい

本アプリは予定の「追加のみ」を行い、既存の予定は読み書きしません。追加された予定の編集・削除は、標準の「カレンダー」アプリで行ってください。

長い文章からまとめて入れたい（まとめて入力）

「まとめて入力」パネルに文章を貼り、「AI用の指示をコピー」→ お使いのチャット AI（Claude / ChatGPT / Gemini など）に貼り付け → 返ってきた JSON を貼り直して取り込みます。取り込んだ予定は一覧で確認してから保存します（勝手に保存されません）。自分の API キー（Anthropic / Google）を「AI 設定」に登録すると、コピーの往復なしにボタン1つで解釈できます。キーは端末内にのみ保存され、文章は選んだ AI 社へ直接送信されます（開発者のサーバはありません）。※ OpenAI のキーは非対応です（ブラウザからの直接接続を許可していないため）。

Support — VoiceCalendar

Last updated: July 19, 2026

VoiceCalendar lets you add events to your device calendar just by speaking. Events are written to whichever calendar you set as the default in iOS.

How to use

  1. Open the app (or say “Hey Siri, ボイカレ 開いて”).
  2. Speak a schedule in Japanese, e.g. “明日10時30分 会議” (a meeting tomorrow at 10:30). The date, time, and title fill the form.
  3. Tap Save to add the event to your default calendar.

It also works as a quick memo: if you don’t say a date/time, the current time is used.

FAQ

Which calendar do events go to?

Your iOS default calendar. Change it in Settings → Calendar → Default Calendar.

Google Calendar?

Add your Google account in Settings → Calendar → Accounts and set it as the default. The app doesn’t talk to Google directly; iOS syncs it.

Deleting events

The app only adds events (write-only) and never reads or modifies existing ones. Edit or delete events in the standard Calendar app.

Batch input from long text

Paste long text into the batch-input panel, copy the generated AI prompt into any chat AI, then paste the returned JSON back to import. Imported events are reviewed in a list before saving. Optionally register your own API key (Anthropic / Google) to interpret with one tap — the key stays on your device and your text goes directly to the provider you chose (there is no developer server). OpenAI keys are not supported (no browser CORS).
