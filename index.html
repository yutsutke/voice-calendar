📥 まとめて入力（長文・AI・JSON）
長い文章から複数の予定・記録をまとめて取り込めます。手順: ① 下の欄に文章を貼る → ②「AI用の指示をコピー」を押して、お使いのチャットAI（Claude / ChatGPT / Gemini など）に貼り付ける → ③ 返ってきた JSON をこの欄に貼り直して「JSONとして取り込み」。取り込んだ予定は下に一度並び、確認してから保存します（勝手に保存されません）。保存の控えは「リスト」に残ります（来歴は音声の記録＝ここからの取り込みは載りません）。⚠ コピーした文面は貼り付け先の AI に渡ります（辞書の言い回しは展開後の実文字列が入ります）。
🤖 AI に直接解釈させる（コピーの往復を省く）には、自分の API キーが要ります。設定は画面下の「詳細設定」→「AI 設定」にあります。
⚙️ 詳細設定
AI 設定（自分の API キーで直接解釈・任意）
自分の API キーを入れると、「まとめて入力」の長文をボタン1つで解釈できます（コピーの往復が不要になります）。詳細設定の「音声を AI で解釈する」もこのキーを使います。入力した内容は自動で保存されます（保存ボタンはありません）。キーはこの端末の中にのみ保存され、開発者のサーバは存在しません。本文（辞書の展開結果を含む）は選んだ AI 社へ端末から直接送信されます。本アプリ専用に使用上限付きのキーを発行するのがおすすめです。共有端末では保存しないでください。※ OpenAI に直接つなぐことはできません（ブラウザからの接続を許可していないため。2026-08-13 に再確認）。GPT を使いたい場合は OpenRouter を選び、モデルに openai/… を指定してください（1つのキーで GPT・Claude・Gemini などを使えます）。
🔤 辞書（言い回しの置き換え）
話した言葉の中の「言い回し」を、登録した文字に置き換えてから解釈します。例: 「メモ 僕のメールアドレス」→ メモ欄に実際のアドレスが入る。長い言い回しほど安全です（短い言葉は他の言葉の中に現れて誤変換します。例: 「メモ」を登録すると「メモリアルホール」が壊れます）。置き換えた内容は来歴に 🔤 で表示されます。登録内容はこの端末の中だけに保存され、外部には送信されません。

💡 使い方の事例（予定と記録）
📅 予定として使う
Hey Siri → ボイカレ開いて → 「明日10時 会議」
明日10:00・タイトル「会議」でカレンダーに入ります。
※詳細設定「話し終わったら自動で保存する」を「日時を言った発話だけ」か「いつでも」に。「しない」の場合は「カレンダーに保存」ボタンを押します。
Hey Siri → ボイカレ開いて → 「明日10時から11時まで会議」
開始10:00・終了11:00・タイトル「会議」で入ります。※自動保存の設定は上と同じ。
Hey Siri → ボイカレ開いて → 「明日10時 会議」→「場所 丸の内」→「タイトル 経営会議」→「終了時間 11時」→「メモ 資料を事前受け取り」→ 保存ボタン
1発話につき1項目ずつ直して組み立てる使い方。
※この使い方では自動保存を「しない」にする必要があります（自動保存が効いていると最初の発話で先に保存されます）。
Hey Siri → ボイカレ開いて → 「30分後に会議」
「30分後に会議が始まる」予定。開始＝今から30分後・終了＝その1時間後（詳細設定「終了を言わなかった時の長さ」で変更可）・タイトル「会議」。開始が未来なので📅予定。※自動保存の設定が必要（「日時を言った発話だけ」で入ります）。
📝 記録として使う
Hey Siri → ボイカレ開いて → 「現在 新宿駅に着いた」
今の日時・タイトル「新宿駅に着いた」で入ります。※自動保存の設定が必要（「日時を言った発話だけ」で入ります）。
💡「今」より「現在」の方が確実に入ります（「今」は後ろに区切りが無いと日時になりません）。
Hey Siri → ボイカレ開いて → 「新宿駅に着いた」→ 保存ボタン
日時を言わなかった発話は、保存ボタンで「今の日時」として入ります。
※自動保存を「いつでも」にすると、この発話も今の日時で自動で入ります（v47）。「日時を言った発話だけ」ならフォームに残る＝ボタンで保存。
Hey Siri → ボイカレ開いて → 「現在 業務終了」→「場所 丸の内」→「メモ 直帰します」→ 保存ボタン
記録も欄指定で組み立てられます。※この使い方では自動保存を「しない」にする必要があります。
Hey Siri → ボイカレ開いて → 「今から3時間開発」
開始＝今・終了＝3時間後・タイトル「開発」。開始が今なので📝記録（これから何をするかの時間の記録）。※自動保存の設定が必要（「日時を言った発話だけ」で入ります）。
Hey Siri → ボイカレ開いて → 「今から15時まで作業」
開始＝今・終了＝15時・タイトル「作業」・📝記録。※自動保存の設定が必要（「日時を言った発話だけ」で入ります）。
📅予定 と 📝記録 は開始の時刻で自動に分かれます＝開始が未来なら予定、今か過去なら記録（「30分後に会議」は開始が30分後＝未来なので予定、「今から3時間開発」は開始が今なので記録）。
保存先を「リスト」「両方」にしている場合は、カレンダーの代わりに／加えてアプリ内のリストに入ります（詳細設定）。Siri で開けるのはアプリ版のみ（この web 版はマイクをタップ）。
自動保存は3段階（詳細設定）＝しない／日時を言った発話だけ（「明日15時に歯医者」「現在 業務終了」）／いつでも（「新宿駅に着いた」も今の日時で入る＝毎回「現在」と言わなくてよい）。「いつでも」は環境音や独り言も入りやすくなります——カレンダーに入れた分はアプリから消せない（追加のみの権限）ので、迷うなら保存先を「リスト」にしておくと1件ずつ消せます。言い淀みだけの発話（「えーっと」）はどの設定でも自動保存しません。
📆 期間で絞る
予定・記録の開始日時で絞ります。リスト・地図・CSV書き出しに同じように効きます。
