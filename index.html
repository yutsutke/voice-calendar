まとめて入力（長文・AI・JSON）
長い文章から複数の予定・記録をまとめて取り込めます。手順: ① 下の欄に文章を貼る → ②「AI用の指示をコピー」を押して、お使いのチャットAI（Claude / ChatGPT / Gemini など）に貼り付ける → ③ 返ってきた JSON をこの欄に貼り直して「JSONとして取り込み」。取り込んだ予定は下に一度並び、確認してから保存します（勝手に保存されません）。保存の控えは「リスト」に残ります（来歴は音声の記録＝ここからの取り込みは載りません）。⚠ コピーした文面は貼り付け先の AI に渡ります（辞書の言い回しは展開後の実文字列が入ります）。
AI 設定（自分の API キーで直接解釈・任意）
ここに自分の API キーを入れると、上の文章をボタン1つで解釈できます（コピーの往復が不要になります）。キーはこの端末の中にのみ保存され、開発者のサーバは存在しません。本文（辞書の展開結果を含む）は選んだ AI 社へ端末から直接送信されます。本アプリ専用に使用上限付きのキーを発行するのがおすすめです。共有端末では保存しないでください。※ OpenAI は非対応（ブラウザからの直接接続を許可していないため）。
詳細設定
辞書（言い回しの置き換え）
話した言葉の中の「言い回し」を、登録した文字に置き換えてから解釈します。例: 「メモ 僕のメールアドレス」→ メモ欄に実際のアドレスが入る。長い言い回しほど安全です（短い言葉は他の言葉の中に現れて誤変換します。例: 「メモ」を登録すると「メモリアルホール」が壊れます）。置き換えた内容は来歴に 🔤 で表示されます。登録内容はこの端末の中だけに保存され、外部には送信されません。
診断（環境・エラー）
使い方の事例（予定と記録）
📅 予定として使う
Hey Siri → ボイカレ開いて → 「明日10時 会議」
明日10:00・タイトル「会議」でカレンダーに入ります。
※詳細設定「話し終わったら自動で保存する」に ☑ が必要。☑ なしの場合は「カレンダーに保存」ボタンを押します。
Hey Siri → ボイカレ開いて → 「明日10時から11時まで会議」
開始10:00・終了11:00・タイトル「会議」で入ります。※☑ の要否は上と同じ。
Hey Siri → ボイカレ開いて → 「明日10時 会議」→「場所 丸の内」→「タイトル 経営会議」→「終了時間 11時」→「メモ 資料を事前受け取り」→ 保存ボタン
1発話につき1項目ずつ直して組み立てる使い方。
※この使い方では自動保存の ☑ を外す必要があります（☑ があると最初の発話で先に保存されます）。
Hey Siri → ボイカレ開いて → 「30分後に会議」
「30分後に会議が始まる」予定。開始＝今から30分後・終了＝その1時間後（詳細設定「終了を言わなかった時の長さ」で変更可）・タイトル「会議」。開始が未来なので📅予定。※自動保存に ☑ が必要。
📝 記録として使う
Hey Siri → ボイカレ開いて → 「現在 新宿駅に着いた」
今の日時・タイトル「新宿駅に着いた」で入ります。※自動保存に ☑ が必要。
💡「今」より「現在」の方が確実に入ります（「今」は後ろに区切りが無いと日時になりません）。
Hey Siri → ボイカレ開いて → 「新宿駅に着いた」→ 保存ボタン
日時を言わなかった発話は、保存ボタンで「今の日時」として入ります。
※日時を言っていない発話は、自動保存の ☑ があっても自動では入りません（フォームに残る＝ボタンで保存）。
Hey Siri → ボイカレ開いて → 「現在 業務終了」→「場所 丸の内」→「メモ 直帰します」→ 保存ボタン
記録も欄指定で組み立てられます。※この使い方では自動保存の ☑ を外す必要があります。
Hey Siri → ボイカレ開いて → 「今から3時間開発」
開始＝今・終了＝3時間後・タイトル「開発」。開始が今なので📝記録（これから何をするかの時間の記録）。※自動保存に ☑ が必要。
Hey Siri → ボイカレ開いて → 「今から15時まで作業」
開始＝今・終了＝15時・タイトル「作業」・📝記録。※自動保存に ☑ が必要。
📅予定 と 📝記録 は開始の時刻で自動に分かれます＝開始が未来なら予定、今か過去なら記録（「30分後に会議」は開始が30分後＝未来なので予定、「今から3時間開発」は開始が今なので記録）。
保存先を「リスト」「両方」にしている場合は、カレンダーの代わりに／加えてアプリ内のリストに入ります（詳細設定）。Siri で開けるのはアプリ版のみ（この web 版はマイクをタップ）。
