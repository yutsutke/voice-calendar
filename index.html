📅 予定として使う
Hey Siri → ボイカレ開いて → 「明日10時 会議」
明日10:00・タイトル「会議」でカレンダーに入ります。
※詳細設定「話し終わったら自動で保存する」に ☑ が必要。☑ なしの場合は「カレンダーに保存」ボタンを押します。
Hey Siri → ボイカレ開いて → 「明日10時から11時まで会議」
開始10:00・終了11:00・タイトル「会議」で入ります。※☑ の要否は上と同じ。
Hey Siri → ボイカレ開いて → 「明日10時 会議」→「場所 丸の内」→「タイトル 経営会議」→「終了時間 11時」→「メモ 資料を事前受け取り」→ 保存ボタン
1発話につき1項目ずつ直して組み立てる使い方。
※この使い方では自動保存の ☑ を外す必要があります（☑ があると最初の発話で先に保存されます）。
📝 記録として使う
Hey Siri → ボイカレ開いて → 「現在 新宿駅に着いた」
今の日時・タイトル「新宿駅に着いた」で入ります。※自動保存に ☑ が必要。
💡「今」より「現在」の方が確実に入ります（「今」は後ろに区切りが無いと日時になりません）。
Hey Siri → ボイカレ開いて → 「新宿駅に着いた」→ 保存ボタン
日時を言わなかった発話は、保存ボタンで「今の日時」として入ります。
※日時を言っていない発話は、自動保存の ☑ があっても自動では入りません（フォームに残る＝ボタンで保存）。
Hey Siri → ボイカレ開いて → 「現在 業務終了」→「場所 丸の内」→「メモ 直帰します」→ 保存ボタン
記録も欄指定で組み立てられます。※この使い方では自動保存の ☑ を外す必要があります。
保存先を「リスト」「両方」にしている場合は、カレンダーの代わりに／加えてアプリ内のリストに入ります（詳細設定）。Siri で開けるのはアプリ版のみ（この web 版はマイクをタップ）。
